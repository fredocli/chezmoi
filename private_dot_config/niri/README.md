l# Niri Keyboard Shortcuts Cheat Sheet

This README summarizes the essential keyboard shortcuts configured in your Niri window manager configuration (`config.kdl`).

> **Note:** `Mod` refers to the **Super** key (Windows key) on a TTY, or **Alt** when running as a nested window.

---

## 🚀 Application Launching & Session
| Shortcut | Action |
| :--- | :--- |
| `Mod + T` | Open Terminal (`alacritty`) |
| `Mod + D` | Run Application Launcher (`fuzzel`) |
| `Super + Alt + L` | Lock Screen (`swaylock`) |
| `Mod + Shift + E` | Quit Niri (shows confirmation) |
| `Ctrl + Alt + Delete` | Quit Niri (shows confirmation) |
| `Mod + Shift + P` | Power off monitors |
| `Mod + Shift + /` | Show "Important Hotkeys" overlay |

---

## 🪟 Window & Co   umn Management
| Shortcut | Action |
| :--- | :--- |
| `Mod + Q` | Close active window |
| `Mod + F` | Maximize active column |
| `Mod + Shift + F` | Fullscreen active window |
| `Mod + M` | Maximize window to edges (no gaps/borders) |
| `Mod + C` | Center focused column |
| `Mod + Ctrl + C` | Center all visible columns |
| `Mod + Ctrl + F` | Expand column to available width |
| `Mod + V` | Toggle window between Floating and Tiling |
| `Mod + Shift + V` | Switch focus between Floating and Tiling |
| `Mod + W` | Toggle vertical tabbed column display |

---

## 🎯 Navigation (Focus)
| Shortcut | Action |
| :--- | :--- |
| `Mod + Left` / `Mod + H` | Focus column left |
| `Mod + Right` / `Mod + L` | Focus column right |
| `Mod + Down` / `Mod + J` | Focus window down |
| `Mod + Up` / `Mod + K` | Focus window up |
| `Mod + Home` | Focus first column |
| `Mod + End` | Focus last column |
| `Mod + Page_Down` / `Mod + U` | Focus workspace down |
| `Mod + Page_Up` / `Mod + I` | Focus workspace up |
| `Mod + [1-9]` | Focus specific workspace index |

---

## 🔄 Moving Windows & Columns
| Shortcut | Action |
| :--- | :--- |
| `Mod + Ctrl + Left` / `Mod + Ctrl + H` | Move column left |
| `Mod + Ctrl + Right` / `Mod + Ctrl + L` | Move column right |
| `Mod + Ctrl + Down` / `Mod + Ctrl + J` | Move window down |
| `Mod + Ctrl + Up` / `Mod + Ctrl + K` | Move window up |
| `Mod + Ctrl + Page_Down` / `Mod + Ctrl + U` | Move column to workspace down |
| `Mod + Ctrl + Page_Up` / `Mod + Ctrl + I` | Move column to workspace up |
| `Mod + Ctrl + [1-9]` | Move column to workspace index |

---

## 📏 Sizing & Columns Operations
| Shortcut | Action |
| :--- | :--- |
| `Mod + R` | Cycle preset column widths |
| `Mod + Shift + R` | Cycle preset column widths in reverse |
| `Mod + Minus` / `Mod + Equal` | Decrease / Increase column width by 10% |
| `Mod + Shift + Minus` / `Mod + Shift + Equal` | Decrease / Increase window height by 10% |
| `Mod + [` / `Mod + ]` | Consume/expel window left/right |
| `Mod + Comma` | Consume window from right to the bottom of active column |
| `Mod + Period` | Expel bottom window from active column to the right |

---

## 📸 Screenshots
| Shortcut | Action |
| :--- | :--- |
| `Print` | Capture screenshot of interactive area |
| `Ctrl + Print` | Capture screenshot of full screen |
| `Alt + Print` | Capture screenshot of active window |

---

## 🔊 Audio & Brightness Controls
| Key | Action |
| :--- | :--- |
| `XF86AudioRaiseVolume` | Increase Volume (+10%) |
| `XF86AudioLowerVolume` | Decrease Volume (-10%) |
| `XF86AudioMute` | Toggle Audio Mute |
| `XF86AudioMicMute` | Toggle Microphone Mute |
| `XF86MonBrightnessUp` | Increase Backlight Brightness (+10%) |
| `XF86MonBrightnessDown` | Decrease Backlight Brightness (10%-) |
